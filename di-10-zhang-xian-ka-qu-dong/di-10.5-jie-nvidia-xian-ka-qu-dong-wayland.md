# 10.5 NVIDIA 显卡驱动（Wayland）

## NVIDIA 显卡驱动概述

截至 2026 年 11 月，FreeBSD 上仅有两个 NVIDIA 官方驱动版本系列支持 Wayland：

- 580.x 版本，[支持 GPU 型号](https://www.nvidia.cn/drivers/details/281524/)（在页面上点击“产品支持列表”），例如 GeForce 10xx 系列。
- 最新版本（当前为 620.x，如 620.73.04），[支持 GPU 型号](https://www.nvidia.cn/drivers/details/285557/)（在页面上点击“产品支持列表”），例如 GeForce RTX 30xx 系列、GeForce RTX 50xx 系列。

两个版本系列的 GPU 支持型号清单有较大重合（例如 GeForce 16xx、GeForce RTX 30xx 系列），但更早的型号（例如 GeForce 9800 GT）不受支持。

需注意，较老型号系列中仅部分型号受支持，应仔细阅读上述清单。部分型号的支持情况如下：

## 加入 video 组

将指定用户加入 video 组，以便访问显卡设备：

```sh
# pw groupmod video -m 用户名
```

将“用户名”替换为实际用户名。

## 安装显卡驱动

使用 pkg 安装 580.x 版本：

```sh
# pkg install nvidia-drm-kmod-580 nvidia-settings
```

或使用 Ports 安装 580.x 版本：

```sh
# cd /usr/ports/graphics/nvidia-drm-kmod-580/ && make install clean
# cd /usr/ports/x11/nvidia-settings/ && make install clean
```

使用 pkg 安装最新版本：

```sh
# pkg install nvidia-drm-kmod-devel nvidia-settings
```

或使用 Ports 安装最新版本：

```sh
# cd /usr/ports/graphics/nvidia-drm-kmod-devel/ && make install clean
# cd /usr/ports/x11/nvidia-settings/ && make install clean
```

## 配置 NVIDIA 显卡驱动

### 启动 NVIDIA 相关内核模块

执行以下命令配置 NVIDIA 内核模块：

```sh
# sysrc -f /boot/loader.conf hw.nvidiadrm.modeset=1  # 启用 NVIDIA DRM 模式设置
# sysrc -f /etc/rc.conf kld_list+=nvidia-drm         # 加载 nvidia-drm 内核模块
```

## 验证安装

重启 FreeBSD，验证 NVIDIA GPU 驱动是否正常加载。

若配置成功，可看到以下内核消息：

```sh
nvidia0: <NVIDIA GeForce XXXX> on vgapci0
vgapci0: child nvidia0 requested pci_enable_io
vgapci0: child nvidia0 requested pci_enable_io
nvidia-modeset: Loading NVIDIA Kernel Mode Setting Driver for UNIX platforms  580.178.04  Tue Jul  7 12:04:34 UTC 2026
[drm] [nvidia-drm] [GPU ID 0x00000100] Loading driver
sysctl_add_oid: can't re-use a leaf (hw.dri.debug)!
[drm] Initialized nvidia-drm 0.0.0 for nvidia0 on minor 0
```

若所安装的驱动不支持当前 GPU 型号，可看到以下内核消息：

```sh
NVRM: The NVIDIA NVIDIA GeForce XXXX GPU installed in this system is
NVRM:  supported through the NVIDIA 580.xx Legacy drivers. Please
NVRM:  visit http://www.nvidia.com/object/unix.html for more
NVRM:  information.  The 615.71.09 NVIDIA driver will ignore
NVRM:  this GPU.  Continuing probe...
nvidia-modeset: Loading NVIDIA Kernel Mode Setting Driver for UNIX platforms  615.71.09  Fri Sep  4 21:13:40 UTC 2026
```

上述内核消息中的版本号随驱动更新而变化，以实际安装的版本为准。

## 故障排除

以下内容基于 KDE Plasma 6.8.3 与 Chromium 158.0.8127.36（2026 年 11 月 FreeBSD Ports 中的版本）。

### KDE Plasma 鼠标光标消失

表现为 KDE Plasma 启动数秒后鼠标光标消失；大幅度向左前方移动鼠标时，光标短暂出现在显示器左上角，随后再次消失。

临时解决方法是禁用硬件光标，改用软件光标。例如，KDE Plasma 启动脚本 `kde.sh` 可写为：

```sh
#!/bin/sh

# 使用软件渲染的鼠标光标
export KWIN_FORCE_SW_CURSOR=1

dbus-launch ck-launch-session startplasma-wayland
```

KDE 官方文档指出，`KWIN_FORCE_SW_CURSOR` 仅建议用于调试，常规使用硬件光标可获得更好的性能。

### Chromium 窗口闪烁或网页崩溃

Chromium 在 Wayland 会话下可能出现窗口闪烁，打开视频网站（如哔哩哔哩）时容易发生网页崩溃。

临时解决方法是让 Chromium 使用 X11 Ozone 后端，而非 Wayland 后端。仅设置 `XDG_SESSION_TYPE=x11` 不足以覆盖 Chromium 的后端选择，须同时传入 `--ozone-platform=x11`。例如，Chromium 的启动脚本 `chrome.sh` 可写为：

```sh
#!/bin/sh

# 切换到 X11 模式，并强制使用 X11 Ozone 后端
export XDG_SESSION_TYPE=x11

chrome --ozone-platform=x11 "$@" &
```
