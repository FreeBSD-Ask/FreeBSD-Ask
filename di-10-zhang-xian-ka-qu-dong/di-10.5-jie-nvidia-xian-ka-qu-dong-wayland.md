# 10.5 NVIDIA 显卡驱动（Wayland）

## 概述

目前（2026 年 11 月），在 FreeBSD 里仅有两个 NVIDIA 官方驱动版本系列可用于支持 Wayland 的运行：

- 580.x 版本，[支持 GPU 型号（在页面上点击“产品支持列表”）](https://www.nvidia.cn/drivers/details/281524/)（例如 GeForce 10xx 系列）。

- 最新版本（当前如 620.x 版），[支持 GPU 型号（在页面上点击“产品支持列表”）](https://www.nvidia.cn/drivers/details/285557/)（例如 GeForce RTX 30xx 系列、GeForce RTX 50xx 系列）。

这两个版本系列的支持 GPU 型号清单有相当的重合面（例如 GeForce 16xx 系列、GeForce RTX 30xx 系列）。但是，更老旧的 GPU 型号（例如 GeForce 9800 GT）则不被支持。

另外，需要注意的是：对于较老的 GPU 型号系列，只有其中部分 GPU 型号被支持；上述支持 GPU 型号清单应被仔细阅读。例如，对 GeForce 7xx、9xx、10xx、16xx 和 GeForce RTX 30xx 的部分型号支持情况：

## 将需要运行 Wayland 桌面环境的用户加入 video 组

将指定用户添加到 video 组，以便访问显卡设备：

```sh
# pw groupmod video -m 用户名
```

## 安装显卡驱动程序

安装 580.x 版本：

```sh
# pkg install nvidia-drm-kmod-580 nvidia-settings
```

安装最新版本：

```sh
# pkg install nvidia-drm-kmod-devel nvidia-settings
```

或使用 Ports 安装 580.x 版本：

```sh
# cd /usr/ports/graphics/nvidia-drm-kmod-580/ && make install clean
# cd /usr/ports/x11/nvidia-settings/ && make install clean
```

或使用 Ports 安装最新版本：

```sh
# cd /usr/ports/graphics/nvidia-drm-kmod-devel/ && make install clean
# cd /usr/ports/x11/nvidia-settings/ && make install clean
```

## 修改相关配置文件

执行以下命令配置 NVIDIA 内核模块：

```sh
# sysrc -f /boot/loader.conf hw.nvidiadrm.modeset=1    # 启用 NVIDIA DRM 模式设置
# sysrc -f /etc/rc.conf kld_list+=nvidia-drm           # 加载 nvidia-drm 内核模块
```

## 在 KDE Plasma 里鼠标光标消失的问题

故障现象：KDE Plasma 启动后几秒钟，鼠标光标消失。每当将鼠标大幅度向左前方移动，光标会再次出现显示器左上角，然后过几秒钟再消失。

权宜解决方法：禁用硬件鼠标光标，改用软件鼠标光标。例如，KDE Plasma 启动脚本 kde.sh 可写成：

```sh
#!/bin/sh

# Use software mouse cursor instead of hardware cursor
export KWIN_FORCE_SW_CURSOR=1

dbus-launch ck-launch-session startplasma-wayland
```

参考：

- <https://community.kde.org/KWin/Environment_Variables>
- <https://invent.kde.org/plasma/kwin/-/wikis/Environment-Variables>
- <https://bbs.archlinux.org/viewtopic.php?id=292331>

## Chromium 窗口闪烁、打开视频网站（如“哔哩哔哩”）时易发生网页崩溃的问题

权宜解决方法：让 Chromium 运行于 X11 模式中，而不是 Wayland 模式。例如，书写 Chromium 的启动脚本 chrome.sh：

```sh
#!/bin/sh

# Switch to X11 mode
export XDG_SESSION_TYPE=x11

chrome $@ &
```
